    Omni v1.6.0 Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Ship multi-voice narration with karaoke subtitles, automatic 1080p/4K upscaling, and a local preview dashboard for Omni runs.

    Architecture: Keep the existing single-voice pipeline untouched for backward compatibility. Add a multi-voice branch that synthesizes narration per scene/line first, derives clip durations from the real audio, then builds images/clips and merges the global word timeline. Upscaling is an image-stage transform plus parameterized resolution through image prep, clip building, ASS PlayRes, and mux. The preview server is stdlib-only, read-only, localhost-first, and serves the manifest/log/media catalog written by the pipeline.

    Tech Stack: Python 3.14, dataclasses, httpx, Pillow, FFmpeg/ffprobe, http.server.ThreadingHTTPServer, pytest, ruff, mkdocs.

    Spec: User request for v1.6.0 (multi-voice, 4K auto-upscaling, local preview dashboard, tests/docs/examples, commits, push to origin/main).

    Global Constraints

    • Python >=3.14; do not add FastAPI/uvicorn as a hard dependency. The preview server uses stdlib.
    • No new mandatory runtime dependencies. httpx and Pillow are already Omni extras.
    • Preserve the existing single-voice behavior and its tests.
    • All new modules must reach 100% scoped coverage: scripts/omni_media/voices.py, scripts/omni_media/upscale.py, scripts/omni_media/contact_sheet.py, scripts/omni_media/preview.py, scripts/omni_preview.py.
    • Preview binds 127.0.0.1 by default, is read-only, validates Host, resolves media inside the run directory, and supports HTTP Range for video/audio.
    • No secrets, no path traversal, no directory listings.
    • Conventional commits, no Co-Authored-By, push to origin/main only after all gates pass.
    • 4K vertical means 2160x3840, not 3840x2160.
    • FFmpeg has no HQ5x filter. Use Lanczos + unsharp; Real-ESRGAN/ComfyUI/SD WebUI are optional backends.

    Review Focus

    • A/V drift when narration is faster/slower than the target: scene durations must come from synthesized segment durations, not duration / len(scenes).
    • 4K silently downscaled by _prepare_image_bytes or prepare_image: width/height must thread through every image backend.
    • Mixed-resolution clips breaking concat -c copy: one target resolution per run.
    • ASS PlayRes fixed at 1080x1920 while rendering 4K: parameterize it.
    • Preview path traversal/symlink escape and Range handling: reject outside paths; return 206/416 correctly.
    • Multi-voice ASS grouping across speaker changes: never merge words from different speakers into one caption line.
