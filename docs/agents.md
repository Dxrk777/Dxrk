| Agente | ID |
| --- | --- |

| OpenCode | `opencode` |
| Kilo Code | `kilocode` |
| Gemini CLI | `gemini-cli` |
| Cursor | `cursor` |

## Presets

Al instalar (`dxrk-py install --agent <id> --preset <preset>`) se aplican
configuraciones por agente, por ejemplo `full-dxrk` para una integración
completa con el ecosistema (skills, hooks, MCP, memoria).
