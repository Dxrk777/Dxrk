# Release v1.3.0 — DxrkMemory Phases 1–3 + Session SQLite + Swarm (2026-09-27)

> Fuente de verdad: `CHANGELOG.md` § `[1.3.0]`. Esta página es la versión
> navegable de esas notas.

## Destacados

- **DxrkMemory:** Phase 1 local hybrid recall con eval harness.
- **DxrkMemory:** Phase 2 lifecycle con dedupe, decay y KG episodes.
- **DxrkMemory:** Phase 3 agentic tools, budgets y timeline.
- **Sesiones:** backend opcional SQLite-WAL con conformance suite.
- **Swarm:** dispatch real, health honesto y linkage de sesiones.
- **CLI:** comandos `upgrade` y `model`.

## Correcciones

- **memory:** limpieza Phase 0, fixes de duplicados y recall-filter.
- **session:** escrituras atómicas durables, auto-reparación de índice y fix de eviction.
- **cli:** single source of truth para argv en `__main__`.
- **tui:** refresh del badge de tenant en welcome al resumir; re-grabación de demos.

## Refactors

- **session:** CLI unificado sobre FileStorage con migración y sanitización de ids.
- **cli:** split de install, install_steps e install_runtime en módulos enfocados tras facades.
- **utils:** split de session, swarm, hooks_model, fileops, filemerge, bashparse,
  image, messages y permissions/diff en módulos enfocados tras facades.
- **hooks:** split de `utils/hooks.py` en módulos tras facade.
